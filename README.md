# Celestial Healing Sanctuary

A modern, luxury single-page web application for spiritual healing, intuitive reading packages, 1:1 session booking, and 432Hz digital frequency audio products.

## Features
- **Celestial Aesthetic**: Obsidian starry background with interactive constellation canvas.
- **Reading Packages**: Filterable categories (Akashic, Astrology, Tarot, Aura).
- **1:1 Healing Session**: Modality selector with live 7-day interactive date & time slot scheduler.
- **Digital Products**: 432Hz playable audio synthesizer preview, grimoires, and masterclasses.
- **Interactive Booking & Payment Flow**: Multi-step checkout with simulated Card/Apple Pay/PayPal, promo discount code (SOLSTICE), and instant calendar .ICS/Zoom receipt.
- **Sacred Cart Drawer**: Sliding drawer with real-time subtotal.

## Tech Stack
- Vite
- Vanilla JavaScript (ES Modules)
- Modern CSS & Design Tokens
- Web Audio API (432Hz drone synthesis)
